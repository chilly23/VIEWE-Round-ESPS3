1. Introduction
1.1 Features
Brief Info:
1) Button control: One power-on button(long press 2 seconds to power on/off),one reset
button.(Boot key ,for program download),one RST key(hardware reset).
2) Power Supply:Supports dual power modes---DC 5V(recommended 5V 1A adapter,via
USB)+battery,support charge/discharge;USB priority when both connected;Integrated
5V-to-3.3V conversion circuit with power indicator(lights up when 3.3V output is normal.
3) Extended Functions:Integrated I2S digital microphone,I2S DAC(digital-to-analog
conversion),TF (SD) card interface,6-axis IMU sensor (motion detection),capacitive touch
function,USB_OTG interface (for external device expansion),and SD 3078 real-time clock
module (providing precise timekeeping capabilities with low-power backup functionally).
Additionally,the development board features versatile screen interfaces that are compatible with
multiple display sizes,including 1.5-inch,1.75-inch,and 1.85-inch screens,ensuring flexible
adaptation to various application requirement.
4) Backup IO: Multiple GPIO pins led out(IO3/IO8/IO43/IO44) for peripheral
expansion,supporting SPI/I2C/I2S/UART interfaces.
5) Status Indication:RGB LED(Wi-Fi connecting:blue blinking;network success:green solid;low
battery:red blinking;power off:red flash once).
System
1) OS: RTOS
2) CPU: ESP32-S3-N16R8
240MHz
Memory:520KB SRAM,8MB PSRAM,448KB ROM
Storage:16MB Flash
3) Wireless Connectivity:Support 2.4GHz Wi-Fi,BLE 5.0
4) Interface: USB(power supply + program download),USB_OTG,UART,QSPI(screen
control),I2C(IMU/touch),I2S(audio),TF card slot
5) Supported Peripherals:
GPIO,SPI,QSPI,I2C,I2S,UART,ADC,touch sensor,6-axis IMU,TF card controller,RGB LED
PWM,full-speed USB 2.0,timers,watchdogs
Other
1) Operation Temperature：-20~70℃
2) Storage Temperature：-30~80℃
3) Environmental Standard:Complies with RoHS 2.0 and halogen-free requirements

1.3 Basic Activation & Usage
1.Power On/Off:
Power On:Connect to 5V USB or install battery,long press power button for 3 seconds--screen
lights up and displays hot spot name.
Power Off:Long press power button for 2 seconds,RGB LED flashes red once,screen turns off.
2.Wi-Fi hot spot Connection: Search for and connect to the device’s hot spot (e.g., "Xiaozhi-2451")
using a mobile phone/computer; no password is required by default.
3.Network Configuration:
If the browser does not redirect automatically,manually enter the address:http://192.168.4.1
Select a 2.4GHz Wi-Fi(5GHz is not supported) on the configuration page,enter the password,and
submit..
4.Device Activation:
After successful network connection, visit the official website: http://xiaozhi.me to register and log
in to an account.
Click "Console →
Add Device" and enter the first line of numbers displayed on the screen
(device ID).
5.Verification & Usage:
Enter the verification code (second line of numbers displayed on the screen) to complete device
binding.
After binding, configure the voice role (e.g., "Wanwan Xiaohe") and select a language model (e.g.,
Qwen Real-Time) on the "Agent" page to start AI interaction.
Note: The above usage method is for customers who have flashed the Xiaozhi firmware. If you do
not use Xiaozhi, it can be used as an ESP32S3 development board. Materials: Xiaozhi source code,
Xiaozhi firmware, other sample codes
